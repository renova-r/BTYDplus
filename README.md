# BTYDplus

Provides probabilistic buy-till-you-die models for assessing and predicting customer purchase behavior.

Compatibility updates by Renova.

Version 1.2.0.9001: Qualified mcmc.list links to coda in the abe, pggg and pnbd mcmc.DrawParameters Rd files, and converted the pnbd itemize into item entries.

## Install

```r
install.packages("remotes")
remotes::install_github("renova-r/BTYDplus@renova-1.2.0.9001")
```
